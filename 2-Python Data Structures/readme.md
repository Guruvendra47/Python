# Python Data Structures

## Overview

This repository covers the fundamental data structures available in Python, including **Tuples, Lists, Dictionaries, and Sets**. It demonstrates how each data structure stores, organizes, and manipulates data, along with the common operations performed on them.

Understanding Python data structures is essential for writing efficient programs and solving real-world programming problems.

---

## Topics Covered

### Tuples

Tuples are ordered and immutable collections of elements.

Topics include:

- Creating tuples
- Ordered collections
- Immutable nature
- Positive indexing
- Negative indexing
- Tuple slicing
- Tuple concatenation
- Nested tuples
- Accessing nested elements

Example:

```python
person = ("John", 25, 5.9)
```

---

### Lists

Lists are ordered and mutable collections that can store elements of different data types.

Topics include:

- Creating lists
- Mutable collections
- Positive indexing
- Negative indexing
- Nested lists
- Adding elements
- Removing elements
- Updating elements
- Splitting lists
- Concatenating lists
- Appending elements

Example:

```python
fruits = ["Apple", "Banana", "Orange"]
```

---

### List Aliasing and Cloning

The repository demonstrates how lists behave when assigned to another variable.

Topics include:

- List aliasing
- Shared references
- Cloning lists
- Copying lists safely

Example:

```python
list2 = list1[:]
```

---

### Dictionaries

Dictionaries store data as key-value pairs for fast data retrieval.

Topics include:

- Creating dictionaries
- Key-value pairs
- Unique keys
- Mutable and immutable values
- Accessing values
- Adding key-value pairs
- Updating values
- Removing items
- Checking keys
- Retrieving keys
- Retrieving values

Example:

```python
student = {
    "Name": "John",
    "Age": 22
}
```

---

### Sets

Sets are unordered collections of unique elements.

Topics include:

- Creating sets
- Removing duplicate values
- Adding elements
- Removing elements
- Membership testing
- Set operations

Example:

```python
numbers = {1, 2, 3, 4}
```

---

### Set Operations

The repository demonstrates common mathematical set operations.

Topics include:

- Union
- Intersection
- Difference
- Adding elements
- Removing elements
- Checking membership
- Subset verification

Examples:

```python
A.union(B)

A & B

A.issubset(B)
```
