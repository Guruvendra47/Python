# Python Basics

## Project Overview

This repository provides a comprehensive introduction to the fundamental concepts of Python programming. It covers Python data types, variables, expressions, operators, string manipulation, and built-in string methods through practical examples and exercises.

The objective of this repository is to establish a strong foundation in Python programming, enabling learners to write efficient, readable, and maintainable code before progressing to advanced topics such as functions, object-oriented programming, file handling, and exception handling.

---

# Learning Objectives

This repository helps learners to:

- Understand Python's core data types
- Perform arithmetic and logical operations
- Use variables to store and manipulate data
- Work with strings and string operations
- Apply built-in string methods
- Understand indexing and slicing
- Write simple Python expressions
- Build a strong programming foundation

# Topics Covered

## Python Data Types

The repository introduces the primary built-in data types in Python:

- Integer (`int`)
- Float (`float`)
- String (`str`)
- Boolean (`bool`)

Topics include:

- Identifying different data types
- Positive and negative integers
- Decimal values using floats
- Boolean values (`True` and `False`)
- Type checking

---

## Type Conversion

Examples demonstrate converting between different data types using type casting.

Conversions include:

- Integer to Float
- Float to Integer
- Integer to String
- Float to String
- Integer to Boolean
- Float to Boolean

Key concepts:

- Zero converts to `False`
- Non-zero values convert to `True`

---

## Python Expressions

The notebooks explain how Python evaluates expressions using mathematical operators.

Operations covered include:

- Addition
- Subtraction
- Multiplication
- Division
- Integer Division (`//`)
- Modulus (`%`)
- Exponentiation (`**`)

Topics also include:

- Expression evaluation
- Order of operations (BODMAS/PEMDAS)
- Combining multiple operators
