# Python File Handling, Pandas & NumPy

## Overview

This repository covers **Python File Handling**, **Pandas**, and **NumPy**, three essential topics for data processing and analysis. It demonstrates how to read and write files, manipulate structured data using Pandas DataFrames, and perform numerical computations using NumPy arrays.

These concepts form the foundation for data analysis, data engineering, and scientific computing in Python.

---

## Topics Covered

### File Handling

Python provides built-in functions for reading, writing, and managing files.

Topics include:

- Opening files
- Reading files
- Writing files
- Appending data
- File modes (`r`, `w`, `a`)
- Using `with open()`
- Processing file contents
- Working with new lines (`\n`)

---

### Pandas

Pandas is a powerful library for data manipulation and analysis.

Topics include:

- Importing Pandas
- Using aliases (`import pandas as pd`)
- Reading datasets
- Creating DataFrames
- Working with rows and columns
- Selecting columns
- Creating new DataFrames
- Finding unique values
- Boolean filtering
- Saving DataFrames

---

### NumPy

NumPy is a high-performance library for numerical computing.

Topics include:

- Importing NumPy
- Creating arrays
- One-dimensional arrays
- Two-dimensional arrays
- Array indexing
- Array slicing
- Data types (`dtype`)
- Array dimensions (`ndim`)
- Array size (`size`)
- Array shape (`shape`)

---

### NumPy Operations

Topics include:

- Vector addition
- Vector subtraction
- Scalar multiplication
- Hadamard product
- Dot product
- Mathematical operations on arrays

### Data Visualization

Topics include:

- Using Matplotlib with NumPy
- Creating basic visualizations
- Working with numerical data
