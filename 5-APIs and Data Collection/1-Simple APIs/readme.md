# Python APIs with PyCoinGecko

## Overview

This repository demonstrates how to work with **Application Programming Interfaces (APIs)** in Python. It covers API fundamentals, REST APIs, HTTP requests and responses, working with JSON data, using the **PyCoinGecko API** to collect cryptocurrency data, processing data with **Pandas**, and visualizing time series data using **Plotly**.

These concepts are essential for building applications that retrieve real-time data from external services and perform data analysis.
