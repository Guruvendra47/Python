# Python Variables and Expressions

## Overview

This repository introduces Python expressions, arithmetic operators, variables, and assignment operations. It demonstrates how Python evaluates mathematical expressions, stores values in variables, and performs calculations using variable references.

These concepts form the foundation of Python programming and are used throughout every Python application.

---

## Topics Covered

### Python Expressions

Expressions are combinations of values and operators that produce a result.

Topics include:

- Arithmetic expressions
- Mathematical calculations
- Expression evaluation

---

### Arithmetic Operators

The repository covers the following operators:

| Operator | Description |
|----------|-------------|
| `+` | Addition |
| `-` | Subtraction |
| `*` | Multiplication |
| `/` | Division |
| `//` | Integer Division |
| `%` | Modulus |
| `**` | Exponentiation |

---

### Order of Operations

Python follows the standard mathematical order of operations.

Topics include:

- Parentheses
- Multiplication before addition
- Division
- Nested expressions

---

### Variables

Variables are used to store values that can be accessed and modified throughout a program.

Topics include:

- Variable creation
- Variable assignment
- Reassigning values
- Storing expression results

---

### Assignment Operator

Using the assignment operator (`=`) to assign values to variables.

Example:

```python
x = 10
```

---

### Variable Operations

Using variables in mathematical calculations.

Examples include:

- Addition
- Division
- Updating variable values
- Reusing variables

---

### Variable Naming

Best practices for naming variables.

Topics include:

- Meaningful variable names
- Snake case naming convention
- Readable code

Example:

```python
total_minutes
total_hours
```

---

### Practical Example

Using variables to convert minutes into hours.

Example:

```python
total_minutes = 142
total_hours = total_minutes / 60
```
