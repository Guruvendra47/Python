# Python Data Types

## Overview

This repository introduces the fundamental data types available in Python. It covers integers, floating-point numbers, strings, and Boolean values, along with the use of the `type()` function and type casting between different data types.

Understanding Python data types is essential for writing correct and efficient programs, as every value in Python belongs to a specific type.

---

## Topics Covered

### Data Types

The repository introduces Python's commonly used built-in data types:

- Integer (`int`)
- Float (`float`)
- String (`str`)
- Boolean (`bool`)

---

### Integer (`int`)

Topics include:

- Positive integers
- Negative integers
- Whole numbers
- Integer representation

Example:

```python
10
-25
100
```

---

### Float (`float`)

Topics include:

- Decimal numbers
- Real numbers
- Floating-point values

Example:

```python
3.14
15.75
-2.5
```

---

### String (`str`)

Topics include:

- Character sequences
- Single quotes
- Double quotes
- Text representation

Example:

```python
"Python"
'IBM'
```

---

### Boolean (`bool`)

Topics include:

- True
- False
- Logical values

Example:

```python
True
False
```

---

### Identifying Data Types

Using the built-in `type()` function to determine the type of an object.

Example:

```python
type(100)
type(3.14)
type("Python")
type(True)
```

---

### Type Casting

Converting one data type into another.

Conversions covered:

- Integer to Float
- Float to Integer
- String to Integer
- Integer to String
- Float to String
- Integer to Boolean
- Boolean to Integer
- Boolean to Float

---

### Boolean Conversion

Examples include:

```python
bool(1)

bool(0)

int(True)

int(False)
```
